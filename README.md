# Itihāsa Through Data

A research series testing the two Itihāsas, the **Mahābhārata** and the **Rāmāyaṇa**, against independent,
older evidence: pre-registered methods, open data, stated uncertainty.

By Jithendra Varma Chamarthi ([ORCID 0000-0001-9467-5612](https://orcid.org/0000-0001-9467-5612)).

**Principles.** The tradition's own word, *itihāsa*, is respected. Each paper states what the evidence supports and
what it does not. Absence from older texts means "not yet found", never "did not exist". Methods are fixed before results.
